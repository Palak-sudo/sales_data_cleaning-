# Sales Data Cleaning & Analysis Project

## Overview
This project focuses on cleaning and analyzing sales data using Excel and Power BI to generate meaningful business insights. The project includes data preprocessing, KPI analysis, dashboard creation, and business recommendations based on sales performance.

---

## Objective
The main objective of this project is to:

- Clean and organize raw sales data
- Handle missing and duplicate records
- Create meaningful KPIs
- Build an interactive dashboard
- Analyze sales trends and regional performance

---

## Dataset
- Sample sales dataset sourced from Kaggle
- Includes sales transactions, regions, product categories, orders, and profit information

---

## Data Cleaning Steps
The following data cleaning operations were performed in Excel:

- Removed duplicate records
- Handled missing values
- Converted date columns into proper format
- Standardized category names
- Removed outliers for accurate analysis

---

## Key Performance Indicators (KPIs)
The dashboard includes the following KPIs:

- Total Sales
- Total Orders
- Average Order Value
- Total Profit

---

## Dashboard Features
The Power BI dashboard provides:

- Monthly Sales Trend Analysis
- Regional Sales Comparison
- Top Performing Products
- Category-wise Sales Distribution
- Monthly Orders Overview

---

## Charts Used
- Line Chart → Monthly sales trend
- Bar Chart → Sales by region
- Horizontal Bar Chart → Top products
- Pie Chart → Category contribution
- Column Chart → Monthly orders

---

## Key Insights
- West region generated the highest sales
- Technology category contributed the highest revenue
- Peak sales were observed in August
- Top-performing products generated major revenue
- Sales showed seasonal fluctuations

---

## Recommendations
- Focus more on high-performing regions
- Promote top-selling products
- Improve low-performing categories
- Plan inventory based on seasonal demand
- Apply targeted marketing strategies

---
